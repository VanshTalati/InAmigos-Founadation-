HOW TO PREVIEW
--------------
1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser (or use the Live Server extension).

IMPORTANT CONTENT NOTES
-----------------------
- The project descriptions are summarized from the official InAmigos Foundation website.
- The homepage impact figures (200 volunteers, 28 states, 6 causes, 50,000 beneficiaries)
  are displayed as figures published by the foundation. Confirm their reporting period
  and current values before final submission.
- The six project photo areas are deliberately styled placeholders. Replace them with
  official photos only when the NGO has permitted their use.
- The current IAF mark is a temporary, logo-inspired placeholder; replace it with the official logo file when the foundation supplies or approves it.
- The volunteer button currently opens an email to the foundation because no verified volunteer form URL was available. Replace it with the current approved form when confirmed. The contact email button is functional.
- Event entries are from the official website and are dated 2025. They are historical
  examples, not announcements of upcoming events.
- Check official contact details and all copy with your internship coordinator.

GITHUB PAGES PUBLISHING
-----------------------
1. Create a GitHub repository, for example: inamigos-awareness-website
2. Upload index.html, the css folder and the images folder.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. Wait for GitHub Pages to publish the site and open the generated URL.
